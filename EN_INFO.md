## **ABOUT:** 

CostoMirrPars - is a utility made by the developer Costodoston, which parses the official mirrors of some distributions.

**The program currently supports the following distributions:**
Artix Linux
Arch Linux
CachyOS

**The program currently supports the following localizations (depending on the distribution):**
Russia
Belarus
Ukraine
Kazakhstan
United States
United Kingdom
